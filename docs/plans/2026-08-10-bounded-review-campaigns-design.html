Cap campaigns, not reviewer thought Core

Reviewer turns and spend stay uncapped. Landed: immutable round and invocation budgets outside each CLI call.

Availability changes evidence, not safety Models

One model can finish ordinary review. Landed: lead-only, fresh-session, external-reviewed, and cross-model-reviewed labels.

No final vote Closure

Models provide evidence. Landed: the lead closes on file, symbol, and test evidence; extra reviewers never add rounds.

Objective third-round trigger Exception

Disagreement cannot buy another sweep. Landed: only a lead-verified critical/high fix regression opens one targeted final round.

Never touch

  • Per-invocation depth — do not restore turn, spend, or short timeout caps.
  • Explicit reviewer requirements — never silently downgrade them.
  • Pre-merge single-run passes — general and security each run once.

Held constant

  • Lead authority — evidence, not votes, closes findings.
  • Fixed scope — confirmation inspects accepted findings and the fix diff only.
  • Immutable counters — compaction and goal continuation cannot reset them.

Verification gates

  • Skill RED–GREEN–REFACTOR — baseline and revised pressure scenarios.
  • Guard suite — campaign references, counters, evidence labels, and terminal states.
  • Repository checks — npm test, diff check, and version audit.
