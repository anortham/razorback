Miller already deploys hand-written files from docs/site/ via upload-pages-artifact. Landed: same layout, same workflow shape. No Jekyll, no framework, no runtime dependency, so razorback stays a pure-content plugin. Only docs/site is uploaded, which keeps docs/plans/ and docs/specs/ unpublished.

Sibling look, own accent Design

The two tools get pitched together, so the sites should read as a family. Landed: Miller's structural CSS conventions with razorback's own palette pulled from its logo — crimson #B31B1B, ink #141418, cream #FFF4E0. Not Miller's teal.

Never touch

  • Skill content, hooks, manifests — this is a documentation change. No skill body, hook script, or version-bearing manifest moves.
  • README structure — fix the five drifts in place. The README stays the reference document.

Held constant

  • No external fetches — no CDN, no web font, no remote image. The logo is a local SVG.
  • No inline event handlers — script.js is the only script on the page.
  • Commands are copied, never invented — every command traces to this repo or the Miller README.
