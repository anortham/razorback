## Removed code-kb from razorback and cut confirmed workflow waste

**WHAT**
- Every active file is free of code-kb and its tool names: 3 rule sources, 5 host rule copies, 30+ skill and prompt files, `agents/code-reviewer.md`, README, `docs/site/`, Codex and OpenCode docs, 5 manifests, `CLAUDE.md`.
- `skills/using-razorback/references/subagent-toolchain.md` is now `subagent-rules.md`; hook, doctor script, and tests follow.
- `scripts/run-toolkit-integration.mjs` tests Goldfish only; its config holds one `goldfish` record.
- Workflow evaluation: 14 scenarios (was 15). `missing_code_kb` became `audit_unreadable_scope`, `missing_tool_fallback` became `evidence_before_fix`, `unsupported_structural_coverage` was deleted.
- `tests/code-kb-routing.test.mjs` deleted. One guard in `tests/workflow-tool-contracts.test.mjs` fails when an active file names code-kb or one of its tools.
- Workflow cuts: small-fix path states its own rules and loads debugging or TDD skills only when needed; small-fix PR needs granted push authority or one question after the gate; plan ticks are staged in the task commit; no second setup or baseline on worktree re-entry; slow suites are not a baseline; reviewer output is validated once per pass; the approval question asks yes or no for push and PR, and "no" ends at the local branch without a second question.

**WHY**
- The owner phases out code-kb (2026-11-16) and wants no dependency on it. This supersedes the brief constraint "keep the code-kb-first routing wording".

**HOW**
- Skills now name the evidence (read the code, search for callers, prove API shapes), not a tool. Rule 2 carries "A search that finds no caller is not proof that none exists".
- `.gitignore` keeps `.code-kb/` while the owner still has the tool installed. `docs/plans/`, `docs/specs/`, `.memories/`, and done items in `TODO.md` keep their history.

**IMPACT**
- Session bootstrap is 6.5 KB (was 10 KB). `npm test`: 540 pass, 0 fail, 2 skipped. Real Goldfish integration run passed.
- Work is uncommitted on branch `remove-code-kb`. Commit, push, and PR wait for the owner.
