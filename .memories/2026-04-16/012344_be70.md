## Added Codex as first-class supported platform (v0.8.0)

Razorback previously shipped for Claude Code + OpenCode only. This release promotes Codex to peer status alongside them.

### What changed

- **New install path:** `.codex/INSTALL.md` (clone + symlink `~/.codex/razorback/skills` → `~/.agents/skills/razorback`, requires `multi_agent = true`) and `docs/README.codex.md` for detailed docs
- **New tool-mapping reference:** `skills/using-razorback/references/codex-tools.md` maps Claude Code tool names to Codex equivalents (Task→spawn_agent, TodoWrite→update_plan, etc.) and explains subagent dispatch, Julie requirement, and sandbox/worktree detection
- **using-razorback SKILL.md:** "How to Access Skills" now covers all 3 platforms; added "Platform Adaptation" section pointing to codex-tools.md; Execution Model is platform-aware (team-driven is CC-only, subagent-driven is primary on Codex/OpenCode)
- **README.md + CLAUDE.md:** intro, Requirements, Harness split, Execution Model, and bootstrap mechanics updated for three harnesses
- **Version bump:** 0.7.5 → 0.8.0 (feature addition)

### Why

User wanted feature parity with superpowers' Codex support. Codex uses native skill discovery at `~/.agents/skills/`, so no runtime plugin code needed — just install docs, a tool-mapping reference, and platform-aware SKILL.md content.

### How the three bootstraps differ

- Claude Code: `hooks/session-start` reads SKILL.md verbatim
- OpenCode: `.opencode/plugins/razorback.js` injects on first user message, regex-substitutes the Execution Model section
- Codex: native scan of `~/.agents/skills/razorback/`, user reads raw SKILL.md (Execution Model is already platform-aware)

### Impact

Codex users get the full razorback workflow (brainstorm → plan → TDD → execute → review → finish) with `subagent-driven-development` as the primary execution path. Team-driven-development remains a Claude Code exclusive upgrade.

### Out of scope (flagged, not done)

- `scripts/sync-to-codex-plugin.sh` publishing pipeline (superpowers has one for prime-radiant-inc/openai-codex-plugins)
- Codex App compatibility spec for sandbox/worktree detection
