## Visual digest is now opt-in

**WHAT:** Changed the visual digest from automatic to opt-in at all three read moments: `skills/brainstorming/SKILL.md` (User Review Gate), `skills/writing-plans/SKILL.md` (Execution Handoff Step 1), `skills/finishing-a-development-branch/SKILL.md` (Steps 3–8) plus `morning-report-template.md`. Updated the README digest section and `tests/digest-wiring.test.mjs`.

**WHY:** The user reported too much unread HTML. The 2026-08-07 design decision said "Automatic at the three read moments"; the user reversed that decision in this session: digests only when asked.

**HOW:**
- Each wiring region now says the digest is opt-in — written only when the user asked in the session or in project instructions, never unprompted.
- Review-gate and plan-save announcements no longer name a digest by default; a conditional sentence adds it when one was requested.
- Morning-report git add / terminal-pointer lines treat the `.html` sibling as conditional.
- The guard test keeps the `digest-kit.md` region check and now also pins `/opt-in/` in each region, so a future edit cannot silently revert to automatic.

**IMPACT:** No skill writes an HTML digest unprompted anymore. The digest kit and layout contract are unchanged — the feature still works on request. The 2026-08-07 design doc's Timing row is historical and now superseded by this decision.
