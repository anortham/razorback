## Added quick-fix tier (fixing-small-issues skill + Change Tiers policy)

**WHAT:** New `skills/fixing-small-issues/SKILL.md` — a triage-first tier below brainstorming's Lightweight path for small, local, reversible changes. Plus a `## Change Tiers` section in `RAZORBACK.md`, routing wire-ins (brainstorming triage gate, using-razorback execution model, using-git-worktrees exemption, systematic-debugging cross-ref), README/CLAUDE.md doc lines, `tests/quick-fix-tier.test.mjs` (11 process gates), and design doc `docs/plans/2026-07-02-quick-fix-tier-design.md`.

**WHY:** Two real incidents — a submit-button double-submit bug and a 2-property CSS tweak both triggered worktree creation + full ~6-min test-suite baseline runs *before the agent looked at the issue*. Root causes: `using-git-worktrees` Step 4 baseline verification fires on worktree creation; no tier existed below Lightweight; the worktree escape hatch required per-instance user consent; anti-rationalization tables correctly blocked agents from judging process "overkill."

**HOW:** Structural tier with *objective* criteria (≤ 2 source files, ~20 lines, no contract/dependency changes, single-revert reversible, Miller-confirmed target), so it stays compatible with the anti-rationalization philosophy — measured gate, not judgment call. Iron Law: NO INFRASTRUCTURE BEFORE INVESTIGATION. Objective escalation triggers (3rd file, ~2× budget, shared/public-code root cause, 2nd failed attempt, dependency/module change). Bidirectional rationalization table counters both downscaling abuse and ceremony reflex.

**Validation (writing-skills TDD):** RED — two baseline subagent simulations without the skill reproduced the full ceremony (worktree + 6-min suite before opening code; CSS agent concluded ceremony would consume the entire 20-min demo window). GREEN — with the skill, both scenarios route investigate → triage → in-place fix → affected-scope verify; escalation scenario correctly stopped on the shared-code trigger and rejected an in-budget symptom workaround. REFACTOR — added "narrow workaround keeps it in budget" counter-row from that finding.

**IMPACT:** Small fixes no longer pay worktree/baseline-suite/design-doc/subagent ceremony; standard-tier flow unchanged (option 2 — flipping worktree defaults — deliberately not done). 59/59 tests pass; manifests in sync at 0.18.2 (version bump left for next release).
