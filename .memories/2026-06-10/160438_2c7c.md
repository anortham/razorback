## Added Cursor Agent / Composer delegation skill

### WHAT
- Added a new `skills/cursor-agent/SKILL.md` skill for explicit Cursor Agent / Composer delegation.
- Added regression coverage in `tests/cursor-agent-skill.test.mjs`.
- Updated `skills/subagent-driven-development/SKILL.md` with a short pointer for explicit Cursor/Composer delegation.
- Added `cursor-agent` to the README skill table.

### WHY
The user now has Cursor subscription capacity and wants Codex to remain the planning/review lead while handing bounded implementation tasks to Composer 2.5 Fast.

### HOW
- The skill pins default model usage to `composer-2.5-fast`.
- It documents `cursor-agent -p` with `--workspace`, `--trust`, `--force`, and resumable `--resume "$CHAT_ID"` fix loops.
- It keeps the safety contract explicit: no push, no release, no deploy, no destructive git, and no edits outside assigned files.
- The review loop is Codex-led with a 3-iteration cap and fresh Cursor rerun fallback.

### IMPACT
Future Codex/Razorback sessions can use Cursor as a fast implementation backend without weakening the core Razorback boundaries: Codex plans, reviews, verifies, and owns acceptance; Cursor Agent implements bounded tasks.
