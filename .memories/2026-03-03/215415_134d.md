## Removed Goldfish dependency from Razorback — focus on Julie only

Brainstormed whether Goldfish could be enhanced to reduce token usage in razorback skills. After exploring multiple approaches (living memory, session scratchpad, smart recall budgeting, structured context snapshots), concluded that:

- **Julie's token reduction is concrete and measurable** — replaces 5-6 Glob/Grep/Read chains with single calls
- **Goldfish's within-session value is unproven** — auto-compaction may handle context continuity well enough
- **Every Goldfish enhancement idea was either a wash or fought the platform** — the write cost of maintaining state roughly equals the read savings

### What changed
- Removed Goldfish references from all 7 skills that had them
- Updated CLAUDE.md, README.md, plugin.json, marketplace.json
- Bumped version to 0.2.0
- Left `docs/plans/` historical records untouched
- Net: 34 insertions, 83 deletions across 11 files

### Key insight
Goldfish still works if its MCP server is installed — the agent uses it naturally via server instructions. But razorback skills no longer prescribe or depend on it. The token efficiency story is Julie's alone.
