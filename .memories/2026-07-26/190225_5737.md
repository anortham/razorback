## Fixed grok-cli skill: headless invocations were unrunnable

Another session reported `razorback:grok-cli` as unusable. Validated every documented flag against the live `grok` CLI (v0.2.111, logged in, default `grok-4.5`) and found two real, reproducible defects — both in the paths agents actually invoke.

### Bug 1 — `grok -p --prompt-file FILE` fails instantly (exit 2)
`-p, --single <PROMPT>` requires its own value. Because `--prompt-file` starts with `--`, clap never treats it as `-p`'s value, so the command dies before any model call: `error: a value is required for '--single <PROMPT>' but none was supplied`.

This broke Code Review, Adversarial Review, and the Quick Reference row — every structured-output path. `-p` and `--prompt-file` are mutually exclusive; correct form is `grok --prompt-file FILE` with no `-p`.

### Bug 2 — resume examples opened the interactive TUI
`-c, --continue` is a boolean flag and `-r, --resume` takes only an optional session ID. Neither accepts the prompt, so `grok -c "follow-up prompt"` passed the prompt as the positional arg that launches the TUI — errors `Device not configured (os error 6)` headless, hangs with a TTY. Fixed to `grok -c -p "..."` / `grok -r <ID> -p "..."`.

Also documented: resuming under a different `--sandbox` than the session was created with is rejected; omit `--sandbox` on resume. And `grok sessions` alone prints subcommand help — use `grok sessions list`.

### Verified-correct claims left alone
Confirmed live rather than assumed: sandbox built-ins `read-only`/`workspace`/`none`; an invalid profile genuinely refuses to start rather than running unsandboxed (the skill's safety claim was accurate); `--json-schema` implies `--output-format json` and returns the envelope with `.structuredOutput`/`.text`/`.usage`/`.total_cost_usd`; `grok models` as the auth probe; delegate flow (`--sandbox workspace --always-approve`) really writes files; the cross-skill schema path and `review-targeting.md` reference both resolve.

### Method note
The skill's flag *descriptions* all matched `grok --help`. Both bugs lived only in the composed example commands — help-text review alone would have passed it. Live execution of each documented command is what caught them.

### Impact
All four review/delegate modes now run end-to-end. Adversarial path verified producing a valid schema-conforming finding. `npm test` 156/156 pass.
