## Language-Agnostic Verification Scope Updates

**WHAT:** Updated active razorback workflow skills to replace broad-suite defaults and runner examples with scope-based verification language.

**WHY:** Generic instructions were pushing agents toward repeated broad test runs, which wastes time on large repos and can override target-repo test tiers.

**HOW:** Added a required Verification Strategy section to planning, introduced scope labels (`worker-red-green`, `worker-ceiling`, `affected-change`, `branch-gate`, `expensive-specialist`), added a verification ledger, and rewired worker, fix, pre-merge, finishing, worktree, review, TDD, and debugging wording to consume project-defined commands.

**IMPACT:** Razorback now owns verification responsibility boundaries while each target repo supplies concrete commands. This preserves TDD discipline without baking in Rust, Python, JS, Go, or other runner assumptions.
