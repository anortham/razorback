## Bundled reviewer skills into razorback (0.10.1, PR #2 merged)

PR #1 (0.10.0) shipped autonomous execution with pre-merge-review but the three adversarial reviewer skills (codex-cli, gemini-cli, claude-cli) were only resolvable from the user-global `~/.claude/skills/` — fresh installs would break. 0.10.1 fixes that.

### Approach

- **Bundled** `skills/codex-cli/`, `skills/gemini-cli/`, `skills/claude-cli/` into razorback directly (not referenced from user-global).
- **Install-path-free invocations.** Rejected `${CLAUDE_PLUGIN_ROOT}/skills/...` as Claude-Code-only. Went with inline schema JSON + `mktemp + heredoc` for the CLI flags that require file paths (`codex --output-schema`, `claude --system-prompt-file`). `claude --json-schema` accepts a string so it gets the JSON inline as `$SCHEMA_JSON`.
- Canonical `schemas/review-output.schema.json` and `adversarial-prompt.txt` kept in-repo for version control; bash examples duplicate the content inline but must mirror the canonicals.

### Codex adversarial review caught 3 real findings (all fixed before merge)

1. **HIGH** — gemini.md invocation never substituted `{{TARGET_LABEL}}` / `{{USER_FOCUS}}` / `{{REVIEW_INPUT}}` placeholders; `$FILE_STAT` and `$COMMIT_LOG` were never appended. Fixed with explicit bash parameter-expansion substitution before calling gemini.
2. **MEDIUM** — gemini adversarial template said "Use Read to inspect files" but gemini-cli doesn't document a `Read` tool. Swapped to harness-generic phrasing.
3. **MEDIUM** — drift between reviewer-prompts and standalone skills: `claude-cli/SKILL.md` had a literal `[paste the adversarial-prompt.txt content here]` placeholder inside a heredoc (a fresh agent would have shipped that string as the system prompt), codex-cli Quick Reference still cited file paths, pre-merge-review claimed gemini-cli had an adversarial section it doesn't. All three fixed.

### Key learnings

- `$(cat ~/.claude/skills/...)` vs `${CLAUDE_PLUGIN_ROOT}/skills/...` were both wrong framings. The actual question is "does the skill need the path at all?" — almost never. Inline the content, use temp files only where the CLI flag forces it.
- Codex catches real bugs even on documentation-heavy PRs. The `[paste ...]` placeholder bug was mine; I wouldn't have caught it without the adversarial pass.
- The user's guidance ("razorback was the new home for those skills, pay attention") called out that I had missed the original intent from the prior PR's brainstorm. Important reminder: reread the user's stated intent before shipping.
