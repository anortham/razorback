## Razorback v0.4.0 — Reduced Process Ceremony

Overhauled three core skills based on real-session data showing the full razorback process 3-4x'd token cost (~380K vs ~100K) for moderate features with no measurable quality improvement.

### Changes
- **Resume over fresh subagents** (`subagent-driven-development`): New `fix-prompt.md` template, explicit guidance to save agent ID and resume implementer for review fixes. Fresh dispatch only as fallback.
- **Brainstorming fast path + lightweight mode** (`brainstorming`): Three paths now — full process, fast path (agreed design → writing-plans), lightweight (agreed design → dispatch implementer directly → code quality review, bypassing writing-plans and subagent-driven-development)
- **Light plans** (`writing-plans`): Task-level granularity for same-session work — acceptance criteria and file paths, no code snippets or step-by-step TDD choreography
- **Conditional spec review** (`subagent-driven-development`): Skip when plan is specific and task is small; code quality review always mandatory
- **Version bump** to 0.4.0

### Impact
For moderate, well-understood features executed same-session, expected token usage drops from ~380K to ~80-100K while maintaining code quality review as the mandatory safety net.
