## Skills evaluated against Anthropic's skill authoring best practices (2026-10-02)

**WHAT:** All 29 skills were evaluated against https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices. Branch `skills-best-practices` rewrites all descriptions, updates `writing-skills` to the current guide, replaces `writing-skills/anthropic-best-practices.md` with a verbatim dated copy (with a departures note), and fixes confirmed recipe defects.

**WHY:** The stored guide copy was a July trim that dropped the description, naming, frontmatter, and checklist sections. `writing-skills` taught "description = when, never what", which the current guide contradicts.

**HOW:**
- Description form follows ponytail (~/source/ponytail): outcome sentence, then triggers, then optional boundary; under 500 chars; no "you".
- Fixed defects: claude-cli review result deleted with REVIEW_ROOT; `claude -r` misuse; requesting-code-review step order; undefined `$SKILL_DIR` in 5 skills; find-polluter false "clean"; stale dispatch-table pointer; `Ruling:` ledger format; worktree ignore check; repo-root paths; dated text; tool requirements; code-kb-required wording; TOCs on 17 long reference files.
- Tests changed: diagnosing-performance and managing-review-campaigns description/path regexes; 2 new find-polluter tests.

**IMPACT:** 455/455 tests pass. Departures kept on purpose: `claude-cli` name, MCP name form. Not done: per-skill multi-model evals, ~90 low-value wording/duplication findings.

**A first evaluation workflow fanned out ~690 agents (2 verifiers per raw finding, no dedup) and the user stopped it for token cost.** Dedup before verifying, and cap verifier counts.
