## Migrated razorback from julie-only to dual julie/miller code-intelligence MCP support (v0.15.0)

Made the whole skill set work with **either** code-intelligence MCP server — julie (Rust, current) or miller (.NET successor, building now) — instead of hardcoding julie.

- **WHAT:** Reworked ~37 files (skills, agents, root docs, manifests) so prose is generic ("code-intelligence MCP") and tool references are capability-first.
- **WHY:** User is building miller as a julie replacement; needed razorback to reference whichever is installed without a second rewrite when julie retires.
- **HOW (design decisions, all user-approved):**
  - Prose → generic "code-intelligence MCP" language.
  - Tool calls → capability verbs + ONE authoritative julie→miller mapping table in `skills/using-razorback/SKILL.md` "Your Toolchain" (mirrored in CLAUDE.md "Code-intelligence MCP Integration Pattern" + the 3 harness reference files).
  - **Lead-facing skills** use capability verbs + light dual hints (lead gets the bootstrap table). **Subagent-facing prompt files** (implementer/fix/reviewer prompts, both code-reviewers) carry INLINE dual tool names because dispatched subagents do NOT receive the using-razorback bootstrap.
  - Scope: skills/, agents/, root docs, manifests/branding. `docs/plans/` + `docs/specs/` left frozen (historical record).
- **KEY DISCOVERY:** miller is NOT a `julie:`→`miller:` prefix swap. It consolidates julie's 8 tools into 7 with different names: `fast_search`→`search`, `get_symbols`/`deep_dive`→`inspect` (depth=summary/full), `get_context`→`context`, `fast_refs`→`trace`, `blast_radius`→`impact`, `edit_file`/`rename_symbol`→`edit`, `manage_workspace`→`workspace`.
- **REVIEW + FIX:** codex (gpt-5.3-codex high) review caught one real error: I mapped find-references to `trace(from=...)` from miller's design doc, but the implemented `TraceTool.cs` uses `target`. Re-verified ALL 7 miller signatures against `~/source/miller/src/**/Tools/*.cs` source (not the spec) and fixed 13 `trace(from)`→`trace(target)` sites. Every other signature confirmed correct.
