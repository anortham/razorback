## Assessment of razorback as a hospital pre-checkin quality/security convention

**WHAT:** Read-only audit of razorback (0.26.2) for fitness as an org-wide pre-checkin quality process (hospital context: quality + security + automated PR review in DevOps).

**Drift bugs found (not yet fixed):**
- `skills/pre-merge-review/SKILL.md:109` documents the claude reviewer with `--tools "Read,Bash"`. The canonical invocation (`reviewer-prompts/claude.md:49`) and the red-flags section (SKILL.md:199) pin `Read,Grep,Glob` and forbid Bash. Line 109 followed literally = write-capable "read-only" reviewer under `--dangerously-skip-permissions`.
- `skills/claude-cli/adversarial-prompt.txt:28` tells the reviewer to "use Bash for read-only investigation" — the claude allowlist blocks Bash. Likely seeded the SKILL.md drift. Fits codex (sandboxed shell) but not claude.
- No guard test lints example-command flag strings against the canonical invocation. The 2026-07-26 grok-cli incident checkpoint proposed exactly this test; never built.

**Gaps for the hospital use case:**
- Zero data-governance content: no skill mentions sensitive data/PHI/provider allowlists; pre-merge review and codex/grok delegation ship full diffs to OpenAI/xAI/Anthropic.
- Security coverage is thin: one "Security concerns?" bullet in inline review; adversarial prompt covers auth/trust boundaries; no secrets scan, dependency/CVE audit, or license check anywhere.
- No CI-side PR review: all review is session-bound pre-push; nothing runs against a PR in DevOps. Razorback already owns the pieces (shared review-output schema, adversarial prompts, validated headless codex/claude invocations) — a pipeline wrapper closes it.
- Convention without enforcement: no CI check verifies plans/morning-report/ledger artifacts exist.
- Rollout: Miller/Goldfish hard deps unpinned; marketplace points at personal repo — org needs mirror + pinning.

**Strengths confirmed:** complete process spine, verification-before-completion gate, auditable morning report + dismissal reasons, 23-file guard suite, tag-pinned CI version gate, objective quick-fix tier, human-owned merge.

**IMPACT:** Findings reported to user as assessment only (no fixes applied). The three drift/test items are quick-fix-tier work when approved.
