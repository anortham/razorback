## Implemented `agy-cli` skill for Antigravity integration

Added `razorback:agy-cli` skill mirroring `claude-cli`, `codex-cli`, and `grok-cli` to enable calling Antigravity as an external model, reviewer, or delegated worker.

- **WHAT:** Created `skills/agy-cli/SKILL.md`, `skills/agy-cli/adversarial-prompt.txt`, and comprehensive tests in `tests/agy-cli-docs.test.mjs`. Updated cross-skill references (`security-review`, `cross-model-convergence`, `claude-cli`, `codex-cli`, `grok-cli`, `README.md`) and test guard suites (`adversarial-prompt-sync`, `recipe-execution`, `reviewer-uncapped`, `review-payload-transport`, `security-checklist-sync`, `review-output-completion`).
- **WHY:** Razorback supports multi-model reviews and external delegations. Antigravity CLI (`agy`) is now supported as an external provider (`google`).
- **HOW:**
  - Handled `agy` CLI specifics: headless prompt `-p "$PROMPT" < /dev/null` vs stdin redirect `agy < FILE`, `--dangerously-skip-permissions` for tool execution, `--sandbox` profile for read-only reviews, and lack of `-C`/`--cwd` flag (using shell `cd`).
  - Handled Gemini backend JSON Schema quirks: stripped `$schema` and normalized `review_completed` enum to boolean `{"type": "boolean"}` so Gemini OpenAPI converter does not error with code 400.
  - Aligned adversarial review prompt with quartet invariants.
  - Integrated with `razorback:security-review` policy gate (`provider: google`).
- **IMPACT:** Enables Antigravity CLI to participate in code reviews, adversarial reviews, second opinions, and autonomous task delegations in Razorback.
