## Implemented Miller API-shape evidence guidance

- **WHAT:** Added explicit anti-guessing guidance to active Razorback workflow surfaces and adapted Superpowers' SDD workspace isolation coverage into Razorback's Node tests.
- **WHY:** The user wanted Razorback to standardize on Miller after Miller's 1.0+ release and prevent agents from inventing symbol/API shapes instead of using tools.
- **HOW:** Updated `using-razorback`, `writing-plans`, SDD dispatch/review prompts, fix prompts, review prompts, parallel dispatch, executing-plans, and verification-before-completion to require Miller-backed evidence for symbol names, function signatures, config shapes, route names, CLI flags, and public contracts. Added `tests/borrowed-superpowers.test.mjs` coverage for `.razorback/sdd` being self-ignored and worktree-local plus the new API-shape guidance contract.
- **IMPACT:** Future implementers, reviewers, fix workers, and ad-hoc agents now have prompt-level instructions to prove API shapes with Miller and report evidence instead of guessing. The SDD scratch workspace behavior borrowed from Superpowers is now executable-tested.
