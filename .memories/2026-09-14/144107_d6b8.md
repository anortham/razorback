## Release 0.43.0 — Upstream Superpowers v6.3.0 Adoption

Adopt improvements and process rigor from Superpowers v6.3.0 while preserving Razorback's code-kb MCP layer, Goldfish memory, quick-fix tier, and autonomous execution model.

- **Brainstorming Three Paths Router**: Introduced Spike, Bounded, and Architectural paths with explicit announcement and one-way ratchet; bounded tasks present short designs directly in chat without spec documents.
- **Worker Subagent Self-Spawn Ban**: Added explicit prohibitions on worker subagents dispatching subagents or reviewers across implementer, fix, and code-reviewer prompts.
- **SDD Process Rigor & Spec Pointer**: Added `**Spec:**` header to plan templates, pre-dispatch conflict scan table in the SDD ledger, small same-shape task batching, reviewer test evidence re-reading rules, and "Rulings I made" finish collection.
- **Codex Multi-Agent Efficiency**: Documented context isolation via `fork_turns: "none"`, event-driven `wait_agent` guidance, explicit model/effort routing, and followup task notes.
- **Interactive Worktree Removal Guard**: Added safe handling refusing `--force` removal on untracked files with a 3-choice menu.
- **Windows Graphviz Portability**: Replaced Unix `which dot` in graph rendering with cross-platform `execFileSync`.
