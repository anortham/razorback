## Task 4: Windows Graphviz Detection Portability

- **WHAT:** Replace `which dot` and shell invocation with `execFileSync('dot', ['-V'])` and `execFileSync('dot', ['-Tsvg'], ...)` in `render-graphs.js`.
- **WHY:** `which` is not available on Windows systems, causing graph rendering checks to fail.
- **HOW:** Replaced `execSync('which dot')` with `execFileSync('dot', ['-V'], { stdio: 'ignore' })` and used `execFileSync` for SVG generation. Added guard test `tests/render-graphs.test.mjs`.
- **IMPACT:** Enables `render-graphs.js` to run portably on Windows as well as Unix.
