## Adopted 4 ideas from Addy Osmani's agent-skills repo (~/source/agent-skills)

Gap analysis (Explore agent) found mostly domain-reference content not worth adopting, plus 4 process-shaped ideas. All implemented via writing-skills TDD (4 RED baselines → edits → 4 GREEN tests → refactor). **User constraint honored: no new stop points** — razorback still pushes long autonomous sessions.

1. **Doubt Pass** (from doubt-driven-development) → new section in `cross-model-convergence`: bounded CLAIM→DOUBT→RECONCILE→STOP cycle (max 3) challenging a design decision pre-implementation via external reviewer. Wired into `brainstorming` full-process step 9, conditional on architecture-quality risk medium/high; explicitly "no user gate and no stop point" — output folds into the spec that flows to the existing review gate. RED showed wrong designs previously uncaught until pre-merge at max sunk cost.
2. **Falsifiable guesses + questioning stop rule** (from interview-me) → `brainstorming`: every clarifying question carries "I'm guessing X because Y — is that right?" (guess first in multiple choice, labeled); stop asking when purpose/constraints/success-criteria are stateable AND last question produced no correction.
3. **Task Slicing** (from incremental-implementation) → new section in `writing-plans`: vertical slices default (horizontal only for genuinely-shared layers or contract-first), risk-first ordering, keep-compilable per task, rollback-friendly ordering, and **"Slice boundaries are not stop points"** — checkpoint and continue immediately; stops remain blocker taxonomy + final PR. GREEN probe confirmed agent continues mid-session after a completed slice. Task template headings now "[Slice or component name]".
4. **New skill `grounding-in-current-docs`** (from source-driven-development): repo-first (Miller search), then fetch current official docs for staleness-risk external APIs, verify exact surface, once per session, lead pastes verified surface into worker prompts; anti-ritual guards; docs-unreachable = not a blocker. README row added.

Skipped deliberately: security/frontend/perf/observability/ci-cd skills (domain knowledge models already have), 7-command lifecycle, separate reviewer agents. Suite green (40+2... all pass, fail 0).
