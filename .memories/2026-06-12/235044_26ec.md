## New skill: cross-model-convergence (Claude↔Codex find-verify-fix loop)

User wanted: "Claude finds problems, Codex verifies and finds more, they go back and forth fixing until both agree nothing real remains" — plus the ability to run it under a goal-driven runner until the goal passes.

- **What:** Created `skills/cross-model-convergence/SKILL.md`. Core rule: *agreement is not the terminator; evidence is* — the loop ends on a **double-clean round** (all approved fixes verified + Claude re-sweep clean + reviewer's *substantiated* re-check clean, same round) or at the round cap (default 4). Setup freezes problem class, reviewer, severity floor (nitpick line), and cap before round 1. One user gate (merged list after round 1); in-scope findings auto-fix thereafter; out-of-scope reviewer proposals get parked and can't hold convergence hostage. Failure Handling covers reviewer outage/content-free replies, disputes, fix-induced regressions, rejected gate, failed cap confirmation. Goal-Driver Integration section defines the goal predicate + per-round CONVERGENCE STATUS block so `/loop` (or a future goal command) can drive it unattended.
