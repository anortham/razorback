## WHAT

Revised `docs/plans/2026-07-03-codex-parallelism-and-plugin-implementation.md` in response to plan review feedback.

## WHY

The review identified a real ordering bug: Task 3's package test was supposed to run before the lead commit, but the package script uses `git archive --ref HEAD`, which cannot see uncommitted Task 2 Codex manifest/assets. The review also identified smaller plan gaps around all-skill packaging assertions, task `Interfaces` blocks, Task 4 verification strength, and PNG generation specificity.

## HOW

Changed Task 3 to require `tests/codex-package-script.test.mjs` to build and commit a hermetic temporary git fixture before invoking the package script, so the worker can run `node --test` during the parallel batch without depending on the source checkout's `HEAD`. Added all-skill archive/frontmatter assertions, per-task `Interfaces` blocks for Tasks 1-4, per-file Task 4 `rg` checks, and a concrete 64x64 under-8KB deterministic PNG requirement.

## IMPACT

The plan now preserves parallel-batch no-commit mode while still allowing Task 3 to TDD and run a meaningful worker gate. The implementation handoff is clearer for workers because each task states what it consumes and produces.
