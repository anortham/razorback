Updated Razorback's active instruction surfaces so agents and subagents are pushed toward Miller as the required code-orientation and symbol-awareness layer.

- **WHAT:** Reworded README, CLAUDE/AGENTS guidance, install docs, manifests, using-razorback toolchain table, worker prompts, review/fix/debug/TDD/planning skills, and harness tool mappings from Julie/generic code-intelligence-MCP language to Miller-first wording.

- **HOW:** Used Miller for repo orientation, left dated historical docs/plans untouched, removed active Julie/generic wording from live surfaces, and kept capability-first guidance mapped to Miller tools (`context`, `search`, `inspect`, `trace`, `impact`, `workspace`). Also fixed an existing documentation test wording mismatch in `skills/using-git-worktrees/SKILL.md`.
- **IMPACT:** Future lead sessions, implementer subagents, reviewers, fix workers, and harness install docs now reinforce Miller adoption instead of treating it as optional.
