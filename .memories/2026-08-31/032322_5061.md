## Replaced giant review prompts with reviewer-local artifacts

### WHAT

Added a shared 128 KiB review-payload contract and `skills/security-review/scripts/prepare-review-artifact`. Grok, Claude, Codex, and pre-merge review now place large complete redacted prompts in `.razorback-review/review-input.md` inside an isolated Git-free reviewer tree. The CLI receives only a small static wrapper containing the artifact path.

### WHY

`--prompt-file` solved command-line argument limits but still injected the entire 255 KB diff into one model turn. Grok ignored the review twice and returned planning placeholders. The user's proposed temporary diff file was the correct missing layer.

### HOW

The helper validates required Target/File stat/Commit log/Diff sections for both small and large prompts, rejects live Git roots and symlinks, writes the artifact with directory mode 0700 and file mode 0600, and keeps one threshold across all reviewer skills. Small prompts remain inline but now include the review instruction and focus. Large wrappers are static except for the path. User focus enters the payload before outbound redaction. Claude and the Grok sandbox-off fallback keep the Read/Grep/Glob allowlist without Bash. The existing evidence validator and two-call Grok campaign cap remain unchanged.

### IMPACT

Large reviews no longer depend on the model digesting a giant first-turn prompt. The 276 KiB regression proves the prompt stays bounded while the artifact retains the complete input. The failed Grok campaign remains terminal; a new user-approved campaign is required to exercise the corrected path against xAI.
