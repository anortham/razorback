## Cut 0.36.1 — Codex reviews reach the model

### WHAT

Bumped all five manifests to 0.36.1 on top of `21b9d0f`, the openai-schema sanitizer.

### WHY

0.36.0 shipped with Codex unmeasured. The probe found that OpenAI rejects the canonical review schema with HTTP 400 `invalid_json_schema`, so every schema-constrained Codex review had failed since 0.35.0 without ever reaching the model.

### HOW

Sanitize the schema for Codex only. Claude and Grok accept the canonical file unchanged, and `validate-review-output` still enforces every stripped constraint on the result.

### IMPACT

Claude, Grok, and Codex are all verified working against the same synthetic repo. The three review failures the user reported are now each traced to a distinct root cause and fixed: unrunnable recipes (0.35.0), Grok's one-turn schema collapse (0.36.0), and OpenAI's schema rejection (0.36.1).
