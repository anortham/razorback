## Removed the $5 spend cap from every review recipe

`--max-budget-usd 5.00` was pinned into the claude reviewer path. The user rejected it: a dollar cap truncates a review mid-flight and trades finding quality for cents.

- **Removed from:** `skills/claude-cli/SKILL.md` (Code Review + Adversarial Review commands, flag bullet, error handling, quick-reference table), `skills/pre-merge-review/SKILL.md`, `skills/pre-merge-review/reviewer-prompts/claude.md`, `skills/finishing-a-development-branch/morning-report-template.md`.
- **Replaced with an explicit anti-drift note** in claude-cli and the reviewer prompt so the flag does not get added back.
- **Kept `--max-turns 15`** — that is a runaway-loop guard, not a spend cap. Reworded its rationale to say so and to raise it freely.
- **Kept** `.total_cost_usd` / `.usage` reporting in the morning report; cost is now reported, not capped.
- codex-cli, grok-cli, and cursor-agent never had dollar caps.

**Verified:** `npm test` — 224 pass, 0 fail. No test guarded the budget string.

**Impact:** external reviews now run to completion. Budget-cap blocker branches are gone from the taxonomy references.
