## Studied ~/source/ponytail for lessons applicable to razorback

**WHAT:** Full read of the ponytail repo (lazy-senior-dev skill, ships to ~20 harnesses) — core SKILL.md, AGENTS.md, hooks, adapters, CI scripts, tests, benchmarks.

**Key findings worth stealing for razorback:**

- **Two-tier adapter model** documented in `docs/agent-portability.md`: plugin-tier (hooks/commands/mode) vs instruction-tier (a compact AGENTS.md copied into `.cursor/rules/`, `.windsurf/rules/`, `.clinerules/`, `.kiro/steering/`, `.github/copilot-instructions.md`, etc.). Reaches editors without formal plugin support almost for free.
- **CI drift guards:** `scripts/check-rule-copies.js` byte-compares all instruction-tier copies against AGENTS.md, plus an "invariant canary" list — load-bearing phrases that must appear verbatim in both SKILL.md and AGENTS.md. `scripts/check-versions.js` requires all 8 version-bearing manifests to share one version AND match the git tag on release-tag CI runs (catches "all stale together", their issue #260). Razorback has `bump-version.sh --audit` but it's manual — no `.github/workflows` found in razorback.
- **Node-based hooks with a shared runtime** (`hooks/ponytail-runtime.js`): env-var platform detection (COPILOT_PLUGIN_DATA / PLUGIN_DATA / QODER_SESSION_ID) and one `writeHookOutput()` that emits each host's JSON shape. Fully unit-tested (`tests/hooks.test.js`, hooks-windows). Razorback's polyglot bash `session-start` degrades on Windows; Node hooks with `commandWindows` in hooks.json are genuinely cross-platform.
- **SubagentStart hook** injects the ruleset into every spawned subagent, with `PONYTAIL_SUBAGENT_MATCHER` regex opt-out. Directly relevant: razorback's dispatched subagents don't get using-razorback/Miller rules today (prompts must name Miller inline).
- **Mode/intensity levels** (lite/full/ultra/off) persisted via flag file, UserPromptSubmit mode-tracker, statusline badge; single SKILL.md filtered per mode by the instruction builder.
- **`ponytail:` ceiling comments + ponytail-debt skill:** deliberate shortcuts carry a greppable comment naming ceiling + upgrade trigger; a skill harvests them into a ledger. Great fit for razorback's fixing-small-issues tier.
- **Honest agentic benchmarks** with a terse-prose control arm and published corrections of their own earlier inflated numbers.
- Skill-content patterns: ordered decision ladder with a stop rule; "lazy about the solution, never about reading"; "ONE runnable check" right-sized test rule; ❌/✅ worked examples per intensity level.

**Razorback already has:** tests/ (13 .test.mjs files incl. version-sync), single-source bootstrap (hook reads SKILL.md verbatim — no copies to drift), 6-harness support.

**Next:** decide which of these to adopt (CI workflow, subagent injection hook, instruction-tier copies, debt-marker convention are the highest-value candidates).
