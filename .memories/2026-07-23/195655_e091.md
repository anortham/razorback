## Added razorback:prototyping skill (TDD-verified) on branch add-prototyping-skill

**WHAT:** New skill `skills/prototyping/` (SKILL.md + LOGIC.md + UI.md), an empirical-question off-ramp from brainstorming, adapted from mattpocock/skills' `prototype` skill. Plus the off-ramp wiring in `skills/brainstorming/SKILL.md` (exception note under the HARD-GATE + a bullet in Understanding the idea) and a README skill-table row.

**WHY:** Razorback's flow went brainstorm → design doc → plan with no sanctioned lane for design questions that only running code can settle (state models with too many edge cases to hold in your head, UIs the user keeps flip-flopping on). Brainstorming's HARD-GATE actually *forbade* prototyping; capable agents either argued in prose or (baseline tests showed) decided the answer themselves and wrote production code in the same pass.

**HOW:** Followed razorback:writing-skills RED-GREEN-REFACTOR.
- RED (2 subagents, no skill): logic agent settled the design itself, wrote production TS alongside a batch PASS/FAIL harness, deleted the harness ("one source of truth"); UI agent built variants on empty top-level routes and planned to "delete the two losers". These verbatim rationalizations became the skill's Excuse/Reality table.
- GREEN (3 subagents, with skill): logic and UI agents stated the question first, built user-drivable instruments (dual-model TUI; ?variant= switcher inside the real dashboard shell), withheld the verdict, planned capture on a `prototype/<slug>` branch; off-ramp agent correctly routed from brainstorming to razorback:prototyping under schedule pressure.
- Key adaptations from upstream: user-renders-the-verdict as the core principle (the RED failure upstream doesn't guard), explicit brainstorming off-ramp with go-ahead line, Miller-first orientation, goldfish checkpoint in capture, `git switch -c prototype/<slug>` capture mechanics.

**IMPACT:** Brainstorming now has a third tool between "keep arguing" and "write the doc". Full guard suite (156 tests) green. Not yet pushed — PR pending user approval.
