## Removed team mode and hardened Julie-first worker behavior

### WHAT
- Deleted the live `skills/team-driven-development/` skill and prompt.
- Collapsed active docs and skill references onto `subagent-driven-development` as the single delegated execution path.
- Simplified the OpenCode plugin so it injects the shared `using-razorback` bootstrap verbatim instead of rewriting the execution-model section.
- Hardened worker prompts so implementers, fix rounds, and review-fix subagents must use Julie before raw file reads and must report the Julie calls they used.
- Hardened review guidance so the lead rejects implementer reports that cannot show Julie-first orientation.

### WHY
- Team mode had become a Claude-only architectural branch with higher token cost and extra maintenance burden.
- The repo was telling two execution stories at once, and the live bootstrap/plugin logic had drifted around that split.
- Lead-level Julie guidance was not enough; subagents were still falling back to raw file exploration and burning tokens.

### HOW
- Updated active docs and skills: `README.md`, `CLAUDE.md`, `docs/README.codex.md`, `docs/README.opencode.md`, `skills/using-razorback/SKILL.md`, `skills/writing-plans/SKILL.md`, `skills/executing-plans/SKILL.md`, `skills/requesting-code-review/SKILL.md`, `skills/pre-merge-review/SKILL.md`, `skills/finishing-a-development-branch/SKILL.md`, `skills/using-git-worktrees/SKILL.md`, and Codex/tooling references.
- Removed the deleted skill files and the empty `skills/team-driven-development` directory.
- Updated worker-facing prompts in `skills/subagent-driven-development/implementer-prompt.md`, `skills/subagent-driven-development/fix-prompt.md`, and `skills/pre-merge-review/fix-dispatch-prompt.md` to make Julie-first orientation explicit and reportable.
- Strengthened reviewer prompts in `agents/code-reviewer.md` and `skills/requesting-code-review/code-reviewer.md`.
- Verified with `node --check .opencode/plugins/razorback.js`, `jq empty` on the edited JSON manifests, and an `rg` sweep showing no remaining live `team-driven-development` / `Agent Teams` references outside historical docs.

### IMPACT
- Razorback now has one delegated execution story instead of two competing ones.
- OpenCode bootstrap logic is simpler and no longer needs a special execution-model rewrite.
- Worker prompts now give the lead a concrete enforcement hook for token-efficient Julie usage.
- Historical design docs remain intact as history, while the live product surface reflects the new direction.
