## Made delegation and plan files optional (workflow reduction item 2)

- **WHAT:** The current agent now does one coherent task directly: no plan file, worker, or task report. `writing-plans` has a new "When to Write a Plan File" section (handoff, multi-session, coordination). Plans describe outcomes, constraints, ownership, and checks, and no longer prewrite implementation code; `task-templates.md` dropped its code blocks. A recorded prior authorization can replace a second plan approval when the plan adds no new consequential choice. `subagent-driven-development` is now only for independent tasks or tasks with a clear context benefit. `executing-plans` is the default plan runner. The brainstorming bounded path implements directly, then verifies, commits, and reports in chat.
- **WHY:** TODO item: a bounded task must finish without a worker, plan file, task report, or repeated approval of intent the user already gave.
- **HOW:** Updated routing in `using-razorback`, `codex-tools.md`, `README.md`, and `docs/site/index.html`. Replaced the "including one task" routing tests with checks for the new defaults, plus a plan-file test.
- **IMPACT:** CLAUDE.md "Primary execution path" still says SDD applies even to a single task; item 4 fixes it with the other CLAUDE.md sections. Goldfish checkpoint rules in the execution skills are item 3.
