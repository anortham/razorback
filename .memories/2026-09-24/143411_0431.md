## Updated the workflow contract (workflow reduction item 4)

- **WHAT:** `CLAUDE.md` (and the `AGENTS.md` symlink) now describes proportionate process: the default path is one coherent task in the current agent. Delegation is for independent tasks or a clear context benefit, and plan files are only for handoff, multi-session, or coordination. code-kb and Goldfish are optional. "What Not to Change" now protects proportionate process, outcome checks, the anti-rationalization tables (which guard both directions), two-pass review, evidence-first exploration, and the safeguards. Rewrote five workflow-eval cases: `single_task` (the lead implements directly; dispatch, a plan file, a design-approval round, or a routine checkpoint is forbidden), `missing_code_kb` (native search is required; blocking or asking to restore code-kb is forbidden; an unreadable scope is reported as a gap or gets one question), `checkpoint` (a routine commit forbids a checkpoint), `parallel_commit` (a decision commit requires a checkpoint before staging), and `interrupted_run` (recall is optional). Grader tests were updated, and two were added. README and site core-process text updated.
